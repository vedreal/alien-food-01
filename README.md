Entry for the [make.fun bounty](https://make.fun/bounty/u-po-pu-one-star-five-stars-for-the-food-f9166ee7): one sentence, at most 200 characters, in the voice of an alien tourist giving planet Earth a one-star review while still slipping in a real compliment about the food.

> One star: the locals shout at small glowing rectangles all day, but the noodles — the noodles almost made the 400-light-year trip worth it.

`main.py` writes the single review sentence to `/output/entry.txt` and validates that it is 1–200 characters.
